 Finance Dashboard UI

A modern and responsive Finance Dashboard built using React.js with TypeScript. It provides a clean interface to visualize financial data like transactions, balance trends, and spending insights.

## 🚀 Live Demo
https://react-ts-fglqy1kh.stackblitz.io

 📂 GitHub Repository
https://github.com/Aakhya16/Finance-Dashboard-UI

 Features
- Dashboard overview with summary cards  
- Time-based visualization (balance trends)  
- Transaction list with details  
- Categorical visualization (spending breakdown)  
- Search and filtering functionality  
- Fully responsive design  

 Tech Stack
- React.js  
- TypeScript  
- Recharts  
- CSS  

 Installation
git clone https://github.com/Aakhya16/Finance-Dashboard-UI.git  
cd Finance-Dashboard-UI  
npm install  
npm start  

 Note
This project is a frontend UI implementation and does not include backend functionality.
